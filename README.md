# CSharpAtlas

C# のコード例、例外、コンパイルエラー、仕組みをひとつにまとめる逆引きリファレンスです。

## 現在の構成

- ASP.NET Core (.NET 10)
- 記事データは `src/CSharpAtlas.Web/content/items.json`
- `/api/items` で検索・種類絞り込み
- `/api/items/{id}` で個別記事取得
- コード、例外、コンパイルエラー、論理エラー、仕組みを同じ検索対象にする
- 関連項目を相互リンクする
- `/playground.html` で C# のコンパイル診断を確認できる
- `/api/playground/compile` で Roslyn による CSエラー・警告の診断を返す

## 起動

```bash
dotnet run --project src/CSharpAtlas.Web/CSharpAtlas.Web.csproj
```

起動後、表示されたローカルURLをブラウザで開いてください。

## プレイグラウンド

現在のプレイグラウンドは **コンパイル診断のみ** です。入力したコード自体は実行しません。

任意コードをサーバー上で実行すると Web サーバー本体のファイル・ネットワーク・CPU などへアクセスされる危険があるため、実行機能を追加する場合は Web サーバー本体とは分離し、CPU時間・メモリ・ファイル・ネットワークを制限できる隔離環境を前提にします。
